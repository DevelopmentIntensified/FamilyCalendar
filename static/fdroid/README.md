# Family Planz F-Droid repository

Served at https://familyplanz.com/fdroid/repo (issue #287).

Everything under `repo/`, `archive/` and `qr.svg` is generated by
`scripts/fdroid-publish.sh` — never edit it by hand. Until the first release is
published this folder only holds this README, and https://familyplanz.com/android
says "no release yet".

How to add the repo, install, and publish: https://familyplanz.com/android and
`docs/guides/fdroid-repo.md`.
